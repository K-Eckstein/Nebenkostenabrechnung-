# Nebenkostenabrechnung

Eine kostenlose, lokale Web- und Desktop-Anwendung zur rechtskonformen Erstellung von Nebenkostenabrechnungen für Vermieter in Deutschland.

## Features
- **CO₂-Aufteilung** nach CO2KostAufG (Stufenmodell)
- **HeizkostenV** (50/50 bis 70/30 frei einstellbar)
- **Pro-rata-Berechnung** bei Mieterwechsel und Leerstand
- **Betriebskosten** mit individuellen Verteilerschlüsseln und eigenen Namen
- **PDF-Export** für Mieteranschreiben und das Finanzamt-Archiv
- **100% lokal** – keine Cloud, kein Tracking, alle Daten bleiben auf dem eigenen Rechner.
